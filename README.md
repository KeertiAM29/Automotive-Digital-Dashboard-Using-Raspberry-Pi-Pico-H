# 🚗 Automotive Digital Dashboard Using Raspberry Pi Pico H

> **Raspberry Pi Pico H-based automotive dashboard** that monitors speed, RPM, engine temperature, and battery voltage in real time using sensors and displays the vehicle parameters on an ILI9341 TFT display, with visual turn indicators and system status alerts.

---

## 📌 Overview

An embedded automotive monitoring system developed using the **Raspberry Pi Pico H microcontroller** and an ILI9341 TFT display (240 × 320 resolution). The system integrates a Hall-effect sensor, DS18B20 temperature sensor, and voltage divider circuit to monitor speed, RPM, engine temperature, and battery voltage.

The dashboard uses RPM averaging and filtering techniques to reduce sensor fluctuations and provides visual indications for left and right turn signals, high temperature, overheat conditions, and low battery status.

---

## 🎯 Objective

To develop a real-time automotive digital dashboard using Raspberry Pi Pico H that integrates multiple sensors and communication interfaces to monitor essential vehicle parameters and display them through a graphical TFT interface.

## 🔄 Working

The Raspberry Pi Pico H acquires sensor data, processes the readings, and updates the dashboard display.

### 1. Speed and RPM Measurement

The Hall-effect sensor detects magnetic pulses generated by a magnet attached to the rotating arrangement. The microcontroller measures the time interval between consecutive pulses using GPIO interrupts and calculates RPM.

- RPM is calculated using pulse intervals.
- An average of 8 intervals is used to smooth RPM readings.
- An exponential filtering technique with a filter coefficient of 0.15 reduces fluctuations.
- Speed is calculated using RPM and the configured wheel diameter of 0.01 m.

### 2. Engine Temperature Monitoring

The DS18B20 digital temperature sensor measures temperature and communicates with the Raspberry Pi Pico H through the One-Wire protocol.

The dashboard displays the temperature in °C and generates alerts based on configured thresholds.

### 3. Battery Voltage Monitoring

A voltage divider consisting of 4.7 kΩ and 1 kΩ resistors scales the battery voltage before supplying it to the ADC input (GP26).

- ADC readings are collected over 20 samples and averaged.
- Battery voltage is calculated using the voltage divider ratio.
- Battery percentage is estimated using the configured voltage range of 7.2 V to 9.6 V.

### 4. Turn Indicator Control

A potentiometer connected to GP27 provides analog input to select the left or right turn indicator.

- Left indicator is controlled through GP12.
- Right indicator is controlled through GP13.
- The LEDs blink at a configured interval of 500 ms.
- Corresponding arrows are displayed on the TFT dashboard.

### 5. Dashboard Display and System Alerts

The ILI9341 TFT display presents speed, RPM, engine temperature, battery voltage, battery percentage, and turn indicators.

The system displays the following status conditions:

| Condition | Threshold | Display Status |
|-----------|-----------|----------------|
| Normal | Temperature below 90°C and battery above 15% | 🟢 Normal |
| High Temperature | ≥ 90°C | 🟠 High Temp |
| Overheat | ≥ 105°C | 🔴 Overheat Warning |
| Low Battery | ≤ 15% | 🔴 Low Battery |
